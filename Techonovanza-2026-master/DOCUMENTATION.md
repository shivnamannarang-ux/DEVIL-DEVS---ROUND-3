# Horizon Bank Starter Site

## Why Was This Site Created?

This website was created as a starter project for a beginner web development competition. It represents a fictional bank called **Horizon Bank**.

The project is intentionally incomplete. The goal is for competitors to study the existing code, understand how the pages work, and improve the website with their own ideas and skills.

The design already gives the project a starting direction:

- A clean banking style
- Two connected pages
- Simple HTML, CSS, and JavaScript
- A homepage for the bank's services
- An About Us page for the bank's story
- A small amount of JavaScript interaction

## What Does the Client Expect?

The client expects a professional banking website that is easy to use and trustworthy. Competitors can improve the website by adding:

- A stronger homepage with more banking services
- A working account registration form
- A working login area or login design
- Savings, loans, cards, and account information sections
- Better form validation and useful error messages
- A customer support or FAQ section
- A contact page or contact details
- A mobile-friendly layout
- More accessible buttons, labels, and navigation
- Attractive images or illustrations
- Clear information about security and privacy
- Better animations or small interactive features
- A footer with useful links and social media links

The client is not asking for a real banking system. Do not collect or store real passwords, card numbers, or private financial information in this practice project.

## How to Open the Website

1. Open the `HTML` folder.
2. Open `index.html` in a web browser.
3. Click the navigation links to visit the About Us page.
4. Open the files in VS Code to study and edit them.

A simple VS Code extension such as Live Server can also be used to preview the project while editing.

## What Is Already Working?

### Homepage

- The navigation links connect the two pages.
- The Services link moves to the services section.
- The Contact link moves to the contact form.
- The Log in button displays a message using JavaScript.
- The email form displays a success message after submission.
- The service cards show three example banking services.

### About Us Page

- The navigation links return to the homepage and its sections.
- The Log in button displays the same message as the homepage.
- The page contains a bank story and three company values.

## Suggested Competition Tasks

Start with small changes before attempting a large redesign:

1. Change the bank name and colors.
2. Add another service card.
3. Add labels to the form fields.
4. Improve the login button behavior.
5. Add a FAQ section.
6. Add a savings calculator.
7. Make the layout work on smaller screens.
8. Add a new page only if the competition rules allow it.

## Important Rules for Beginners

- Keep file paths correct when linking HTML, CSS, and JavaScript.
- Use `class` for styles that are reused.
- Use `id` for one special element or JavaScript selection.
- Test the website after every important change.
- Use fake information only. This is not a real banking application.
- Keep the code readable and add comments when a section is difficult to understand.
